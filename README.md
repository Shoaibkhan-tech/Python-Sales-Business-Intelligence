# Python Sales & Business Intelligence Dashboard

An interactive sales analytics dashboard built using Python.

## Features
- Total Revenue and Profit analysis
- Total Orders and Units Sold
- Monthly Revenue Analysis
- Top Selling Products
- Revenue by Category
- Regional Sales Performance
- Interactive data table
- Downloadable Sales Reports

## Technologies Used
- Python 3.11
- Pandas
- NumPy
- Streamlit
- Matplotlib
- Plotly
- Openpyxl

## Installation

1. Clone this repository.
2. Create a virtual environment:

   python -m venv venv

3. Activate it:

   .\venv\Scripts\Activate.ps1

4. Install dependencies:

   pip install -r requirements.txt

5. Run the dashboard:

   streamlit run app.py

## Project Structure

- app.py - Main dashboard application
- data/ - Sample sales dataset
- assets/ - Dashboard CSS styling
- requirements.txt - Python dependencies

## Note
This project uses sample sales data for demonstration purposes.
